# Contribuer

Les contributions sont bienvenues, en particulier pour :

- améliorer la documentation d'installation ;
- proposer des exemples de types de semaine ;
- améliorer la normalisation des ingrédients ;
- ajouter des outils facultatifs de validation JSON ou d'export ;
- documenter d'autres assistants ou intégrations Airtable.

Merci de ne jamais inclure dans une contribution :

- identifiants de base Airtable réels ;
- clés API ou jetons ;
- historiques de repas privés ;
- informations permettant d'identifier un foyer.

Le projet doit rester utilisable sans automatisation payante et sans architecture inutilement complexe.
